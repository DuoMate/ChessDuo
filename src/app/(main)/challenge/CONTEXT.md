# Module: Challenge Link Landing Page

## Purpose
Landing page for challenge links (`/challenge/[code]`). Accepts challenge codes and navigates to game setup.

## Key Files
| File | Purpose |
|------|---------|
| `[code]/page.tsx` | Route entry — challenge acceptance UI |

## Logic & Decisions
- Challenge codes are generated by `@/lib/challenges`.
- Validates challenge code, then redirects to game with pre-set parameters.
- Challenge includes mode, time control, and opponent info.

## Dependencies
- `@/lib/challenges` — challenge link generation and validation
